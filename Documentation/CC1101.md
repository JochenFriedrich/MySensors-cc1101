# Using CC1101 Radios with MySensors

This document describes how to set up and use CC1101 radios with MySensors.

## Introduction

The CC1101 is a low-cost sub-1 GHz transceiver designed for very low-power wireless applications. It is a popular choice for home automation and sensor networks.

This driver adds support for the CC1101 to MySensors, allowing you to use it as a transport layer for your sensor network.

## Wiring

To use the CC1101 with your Arduino, you will need to connect it to the SPI pins. The following table shows the default pin connections:

| CC1101 Pin | Arduino Pin |
|------------|-------------|
| VCC        | 3.3V        |
| GND        | GND         |
| MOSI       | MOSI (11)   |
| MISO       | MISO (12)   |
| SCK        | SCK (13)    |
| CSN        | 10          |
| GDO0       | 2           |

Here is an ASCII art representation of the wiring:

```
CC1101              Arduino
------              -------
 VCC ---------------- 3.3V
 GND ---------------- GND
MOSI ---------------- MOSI (11)
MISO ---------------- MISO (12)
 SCK ---------------- SCK (13)
 CSN ---------------- 10
GDO0 ---------------- 2
```

**Note:** The pin numbers in parentheses are for the Arduino Uno. Please refer to the documentation for your specific board to find the correct SPI pins.

## Configuration

To enable the CC1101 radio, you need to define `MY_RADIO_CC1101` in your sketch or in `MyConfig.h`.

```c++
#define MY_RADIO_CC1101
```

### Configuration Options

The following configuration options are available for the CC1101 radio:

| Option                         | Description                                                                 |
|--------------------------------|-----------------------------------------------------------------------------|
| `MY_CC1101_CS_PIN`             | The chip select pin for the CC1101. Defaults to 10.                         |
| `MY_CC1101_GD0_PIN`            | The GDO0 pin for the CC1101. Defaults to 2.                                 |
| `MY_CC1101_FREQUENCY`          | The base frequency to use. Can be `CC1101_315MHZ`, `CC1101_433MHZ`, `CC1101_868MHZ`, or `CC1101_915MHZ`. Defaults to `CC1101_433MHZ`. |
| `MY_CC1101_CHANNEL`            | The channel number to use. Defaults to 4.                                   |
| `MY_CC1101_SYNC_WORD`          | The sync word to use. Defaults to 0xF543.                                   |
| `MY_CC1101_MODEM_CONFIGURATION`| Selects a predefined modem configuration. See table below.                  |
| `MY_CC1101_POWER_LEVEL`        | The transmit power level. Can be `CC1101_POWER_AUTO` or a fixed power level (0-7). Defaults to `CC1101_POWER_AUTO` for nodes and `CC1101_POWER_6` for gateways. |
| `MY_CC1101_ATC_TARGET_DBM`     | The target RSSI level for ATC. Defaults to -50dBm.                          |
| `MY_CC1101_MAX_POWER_LEVEL`    | The maximum allowable output power level (0-7) for ATC. Defaults to 7.      |
| `MY_CC1101_MIN_POWER_LEVEL`    | The minimum output power level (0-7) for ATC. Defaults to 0.           |

#### Modem Configurations

To select a modem configuration, define `MY_CC1101_MODEM_CONFIGURATION` to one of the following values:

| Configuration                | Modulation | Bit rate  | Freq. Dev. | Max Air time (64-byte payload) | Comment
|------------------------------|------------|-----------|------------|--------------------------------|------------------------
| `CC1101_MODEM_S_BR4_8_FD20`    | GFSK       | 4.8 kbps  | 20 kHz     | ~120 ms                        | Slow and long range
| `CC1101_MODEM_M_BR38_4_FD20`   | GFSK       | 38.4 kbps | 20 kHz     | ~15 ms                         | Medium speed and range
| `CC1101_MODEM_F_BR100_FD50`    | GFSK       | 100 kbps  | 50 kHz     | ~6 ms                          | Fast and balanced
| `CC1101_MODEM_XF_BR250_FD125`  | GFSK       | 250 kbps  | 125 kHz    | ~2.5 ms                        | Fastest and short range

#### Automatic Transmit Power Control (ATC)

The CC1101 driver supports Automatic Transmit Power Control (ATC) when `MY_CC1101_POWER_LEVEL` is set to `CC1101_POWER_AUTO`. This feature automatically adjusts the transmit power to maintain a good connection with the gateway while using the minimum amount of power necessary. This can help to extend the battery life of your nodes.

The target RSSI level for ATC can be configured using the `MY_CC1101_ATC_TARGET_DBM` option. The default value is -50dBm.

The minimum and maximum power levels for ATC can be configured using the `MY_CC1101_MIN_POWER_LEVEL` and `MY_CC1101_MAX_POWER_LEVEL` options. These are indices into the PA_TABLE, from 0 to 7.

### Example Configuration

Here is an example of how to configure the CC1101 radio in your sketch:

```c++
#define MY_RADIO_CC1101
#define MY_CC1101_FREQUENCY CC1101_868MHZ
#define MY_CC1101_CHANNEL 10
#define MY_CC1101_MODEM_CONFIGURATION CC1101_MODEM_M_BR38_4_FD20
#define MY_CC1101_POWER_LEVEL CC1101_POWER_AUTO
#define MY_CC1101_ATC_TARGET_DBM -60
```

This will configure the radio to use the 868MHz frequency band, channel 10, the medium speed modem configuration, and a target RSSI of -60dBm for ATC.
