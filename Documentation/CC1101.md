# Using CC1101 Radios with MySensors

This document describes how to set up and use CC1101 radios with MySensors.

## Introduction

The CC1101 is a low-cost sub-1 GHz transceiver designed for very low-power wireless applications. It is a popular choice for home automation and sensor networks.

This driver adds support for the CC1101 to MySensors, allowing you to use it as a transport layer for your sensor network.

## Wiring

To use the CC1101 with your Arduino, you will need to connect it to the SPI pins. The following table shows the default pin connections:

| CC1101 Pin | Arduino Pin |
|------------|-------------|
| VCC        | 3.3V        |
| GND        | GND         |
| MOSI       | MOSI (11)   |
| MISO       | MISO (12)   |
| SCK        | SCK (13)    |
| CSN        | 10          |
| GDO0       | 2           |

Here is an ASCII art representation of the wiring:

```
CC1101              Arduino
------              -------
 VCC ---------------- 3.3V
 GND ---------------- GND
MOSI ---------------- MOSI (11)
MISO ---------------- MISO (12)
 SCK ---------------- SCK (13)
 CSN ---------------- 10
GDO0 ---------------- 2
```

**Note:** The pin numbers in parentheses are for the Arduino Uno. Please refer to the documentation for your specific board to find the correct SPI pins.

## Configuration

To enable the CC1101 radio, you need to define `MY_RADIO_CC1101` in your sketch or in `MyConfig.h`.

```c++
#define MY_RADIO_CC1101
```

### Configuration Options

The following configuration options are available for the CC1101 radio:

| Option                         | Description                                                                 |
|--------------------------------|-----------------------------------------------------------------------------|
| `MY_CC1101_CS_PIN`             | The chip select pin for the CC1101. Defaults to 10.                         |
| `MY_CC1101_GD0_PIN`            | The GDO0 pin for the CC1101. Defaults to 2.                                 |
| `MY_CC1101_FREQUENCY`          | The base frequency to use. Can be `CC1101_315MHZ`, `CC1101_433MHZ`, `CC1101_868MHZ`, or `CC1101_915MHZ`. Defaults to `CC1101_433MHZ`. |
| `MY_CC1101_CHANNEL`            | The channel number to use. Defaults to 4.                                   |
| `MY_CC1101_DISABLE_ATC`        | If defined, Automatic Transmit Power Control (ATC) will be disabled.        |
| `MY_CC1101_ATC_TARGET_DBM`     | The target RSSI level for ATC. Defaults to -70dBm.                          |
| `MY_CC1101_MAX_POWER_LEVEL_DBM`| The maximum allowable output power level. Defaults to 10dBm.                |
| `MY_CC1101_MIN_POWER_LEVEL_DBM`| The minimum output power level. Used in ATC. Defaults to -20dBm.            |

### Example Configuration

Here is an example of how to configure the CC1101 radio in your sketch:

```c++
#define MY_RADIO_CC1101
#define MY_CC1101_FREQUENCY CC1101_868MHZ
#define MY_CC1101_CHANNEL 10
```

This will configure the radio to use the 868MHz frequency band and channel 10.
